# Base Check-in Client — Technical Documentation

This documentation provides technical and operational information for Base Check-in Client, a client application for integrating attendance and access-control devices from multiple vendors.

## Scope of the documentation

The documentation covers:

- Core system functions and operating procedures.
- Devices that have been successfully tested and connected.
- Connection and integration methods for different device vendors and systems.
- Software versions, release history, and special versions.
- Configuration examples, technical references, and supporting materials.

The system documentation covers integrations with multiple attendance and access-control platforms, including ZKTeco, Hikvision, BioStar, Hanet AI, Idemia, Sunbeam/MyTime, Nuveq, Dahua, Soyal, and others.
